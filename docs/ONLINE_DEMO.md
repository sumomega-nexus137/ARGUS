# ARGUS онлайн: сайт на GitHub и свой домен

## 1. Онлайн-демо на GitHub Pages (работает без вашего компьютера)

Адрес: **https://sumomega-nexus137.github.io/ARGUS/**

Как это устроено:

* Сайт собирает и публикует GitHub Actions — workflow **Online demo (GitHub Pages)**
  (`.github/workflows/pages.yml`). Он запускается сам при каждом push в `main` или в рабочую ветку.
* Во время сборки на серверах GitHub ставятся пакеты реальных данных (с проверкой контрольных сумм), один раз
  запускаются настоящие расчёты ARGUS (стресс-тест, альтернативы CP-SAT для всех 4 политик, дефицит ресурсов,
  узкие места, валидация), и все ответы сохраняются (`scripts/static_demo/record.py`).
* Консоль публикуется как обычные файлы и читает эти сохранённые ответы. Поэтому сайт открыт круглосуточно,
  бесплатно и не требует сервера.
* Онлайн-демо **только для просмотра**: вверху баннер «ОНЛАЙН-ДЕМО» с датой расчётов. Кнопки, которые меняют
  данные (закрыть дорогу, учения BASE → HIGH, импорт, утверждение плана), отвечают понятным сообщением.
  Кнопки «Стресс-тест», «Сформировать альтернативы», «Дефицит ресурсов», анализ узких мест показывают
  сохранённые настоящие результаты. Ничего не выдумано, ничего не выдаётся за «онлайн».

Первый запуск:

1. **Actions → Online demo (GitHub Pages)** — дождитесь зелёной галочки (≈10–15 минут).
   Ручной запуск: там же кнопка **Run workflow**.
2. Готовый сайт workflow кладёт в ветку `gh-pages`. Если GitHub не включил Pages сам, один раз:
   **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `gh-pages` / `(root)` → Save**.
3. Через 1–3 минуты сайт открыт по адресу выше.

## 2. Полная версия в облаке GitHub (Codespaces)

Нужна, если хотите пересчитывать всё вживую.

1. Страница репозитория → **Code → Codespaces → Create codespace on …**
2. Первый запуск ставит всё сам (≈10 минут).
3. Вкладка **PORTS** → порт **3000** → открыть в браузере. Вход: `planner` / `argus2026`
   (руководитель: `commander` / `argus2026`).
4. Чтобы показать другим людям: правый клик по порту 3000 → **Port visibility → Public**.
5. После показа остановите codespace (бесплатные часы на аккаунте GitHub ограничены).

## 3. Свой домен (в том числе бесплатный)

1. Получите домен:
   * бесплатный поддомен, например `argus.is-a.dev` — регистрируется через pull request в
     <https://github.com/is-a-dev/register> (прочитайте их правила);
   * или любой купленный домен (например `.kz`).
2. В DNS домена добавьте запись **CNAME** → `sumomega-nexus137.github.io`.
3. GitHub: **Settings → Pages → Custom domain** → введите домен → **Save**. Когда проверка пройдёт,
   включите **Enforce HTTPS**.
4. **Actions → Online demo (GitHub Pages) → Run workflow**. Сборка сохранит домен (файл CNAME в ветке
   `gh-pages`) и соберёт сайт для него (без `/ARGUS` в адресе).

Через 5–30 минут (обновление DNS) сайт откроется по вашему адресу.

## 4. Оформление

Одна тема «дневной синий»: синяя шапка и меню, светлая серо-голубая рабочая область, панели не белые до рези в
глазах, текст тёмно-синий и чёткий (шрифт Inter встроен в сайт, одинаков на всех компьютерах). Синий цвет на карте
оставлен только воде и глубине затопления.
